# Fonts

`inter-latin.woff2` is [Inter](https://github.com/rsms/inter) by The Inter Project
Authors, the variable version (weights 100–900) with Google Fonts' Latin subset,
as served by fonts.gstatic.com (v20) in October 2026. The page uses weights 400,
500 and 600. `step07_render.py` embeds it in the page so the site makes no
requests to Google (issue #14).
